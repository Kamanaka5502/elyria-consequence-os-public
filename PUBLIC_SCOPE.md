# Public Scope Boundary

This repository is a deliberately bounded public proof surface.

## Included

- Public category definition
- Minimal consequence-admission engine
- Deterministic receipt hashing
- Public CLI demonstrations
- Public architecture and security posture

## Excluded

- Private law bundles
- Customer corridor packs
- Protected BAL/RPA/LPEM proof corpora
- Production deployment credentials
- Runtime keys and secrets
- Hardware enforcement designs
- Confidential adapters
- Internal commercial materials
- Private source archives

The public repository demonstrates the category without disclosing protected enforcement machinery.
